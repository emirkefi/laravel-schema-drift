# Contributing to Laravel Schema Drift

Thank you for considering contributing to Laravel Schema Drift!

## Development & Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure any new features include appropriate tests.
3. Follow PSR-12 coding standards.
4. Submit a Pull Request with a clear description of the problem and your solution.

## Reporting Bugs
- Please check existing issues before opening a new one.
- Use the Bug Report issue template and provide a minimal reproducible example.
